# 🚀 O&M Digital Permits Management System

> Enterprise-level Permit Management System developed during my Software Development Internship using **ASP.NET Core MVC, C#, SQL Server, and ADO.NET**.

---

## 📖 Overview

The O&M Digital Permits Management System is a web-based application designed to digitize industrial work permit management. The project modernizes legacy workflows by migrating permit documents from ASP.NET WebForms to ASP.NET Core MVC while providing a faster, more user-friendly, and maintainable solution.

The application supports multiple permit modules, role-based access, dynamic permit documents, dashboard analytics, and database-driven permit management.

---

- 🔐 Role-Based Authentication
